# Changelog — OrbiTouch ATS

All notable changes to **OrbiTouch ATS** (OrbiTouch HR & Recruitment Consultants / Orbitouch Outsourcing Private Limited) are documented in this file.

## [0.1.0] - Phase 0: Project Foundation & Database Architecture
### Added
- Initialised Laravel application architecture compatible with Hostinger Premium Web Hosting.
- Designed and implemented 44 normalized relational database tables across 7 core migration files covering Organisations, RBAC Roles/Permissions, Users, Login Activities, Teams, Storage Records, Clients, Contacts, Job Requirements, Job Assignments, Screening Questions, Interview Round Definitions, Candidates, Contacts, Skills, Resume Versions, Candidate Documents, Candidate Notes, Applications, Screening Records, Call Logs, Communications, Client Submissions, Client Feedback, Interview Records, Attempts, Feedback, Offers, Revisions, Joining Records, Placements, Replacements, Tasks, Notifications, Email Templates/Logs, Status/Activity/Audit/Import/Backup Logs, System Settings, and Custom Fields.
- Configured GitHub Actions Continuous Integration workflow (`.github/workflows/ci.yml`).
- Established architectural documentation (`PROJECT_PLAN.md`, `ARCHITECTURE.md`, `DATABASE_SCHEMA.md`, `PERMISSIONS.md`, `DEVELOPMENT_PROGRESS.md`).
